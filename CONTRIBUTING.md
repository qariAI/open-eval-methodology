# Contributing to the Open Evaluation Methodology

Thank you for your interest in improving standards for AI Quranic recitation tools.

We welcome contributions from:
- **Quran scholars and teachers** (especially those with ijazah) — to review and validate test cases
- **Computational linguistics researchers** — to improve phoneme and prosody benchmarks
- **AI/ML engineers** — to suggest evaluation methodologies and metrics
- **Developers of competing tools** — your participation makes this more credible, not less
- **Native Arabic speakers** — to validate phoneme test cases and recordings
- **Community members** — bug reports, corrections, translations

---

## Ways to Contribute

### 1. Add or Improve Test Cases
- Navigate to the relevant `tests/` subfolder
- Follow the format described in that folder's README
- Submit a pull request with your additions

### 2. Submit Evaluation Results
- Run your tool (or a competitor's tool) against the benchmarks
- Fill in the results template in `results/`
- Submit a pull request — results are accepted for any tool, not just QariAI

### 3. Review Feedback Quality
If you have ijazah or formal Quran teaching credentials:
- Review the feedback samples in `tests/feedback-quality/`
- Submit your scholarly assessment using the rubric provided
- Your name and credentials will be credited in the results

### 4. Report Issues
- Open a GitHub Issue for incorrect test cases, scoring disagreements, or missing coverage
- Tag issues with: `phoneme`, `tajweed`, `timing`, `feedback`, `demographic`, or `methodology`

---

## Pull Request Guidelines

- Keep PRs focused on one dimension or issue
- Include your reasoning for any scoring changes
- For scholarly reviews, include your credentials in the PR description (optional but appreciated)
- Be respectful — this is a shared resource for the ummah and the research community

---

## Code of Conduct

This project follows basic principles of academic and Islamic ethics:
- Honesty in reporting results, including unfavorable ones
- Respect for all contributors regardless of background
- No manipulation of benchmarks to favor any specific tool
